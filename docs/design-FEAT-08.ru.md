# Дизайн FEAT-08: экспорт своих данных

Статус: черновик на утверждение.

## Предложение

`POST /api/v1/me/export` ставит задачу; воркер собирает ZIP (профиль, свои сообщения каналов и
ЛС, список вложений без самих файлов или с ними по запросу) в `data/exports/<id>.zip`;
`GET /api/v1/me/export/{id}` отдаёт файл по одноразовому тикету. Лимит: один экспорт в сутки на
пользователя, срок жизни файла 24 часа, очистка в `storage/maintenance`.

## Риски

Объём ZIP и нагрузка на SQLite: читать страницами, вне транзакций записи. Экспорт чужих данных
(сообщения других людей в ЛС) не включать. Квота диска: считать в общий лимит хранилища.
