# Дизайн SEC-12: шифрование бэкапов перед офсайтом

Статус: черновик, **нужно решение владельца по инструменту** (новая зависимость).

## Предложение

Переменная `BACKUP_AGE_RECIPIENT` (публичный ключ). Если задана, `backup.sh` шифрует архив
перед офсайт-копией вспомогательным контейнером; локальный архив остаётся нешифрованным
(доступ ограничен правами каталога). Имя зашифрованного файла — `*.tar.gz.age`;
`restore.sh` принимает такой файл и просит файл ключа (`--identity`).

## Выбор инструмента (нужно решить)

- **age**: простой формат, один публичный ключ, нет связки ключей; образ — официальный
  `filosottile/age` или сборка из исходников. Новая зависимость: образ контейнера.
- **gpg**: есть в большинстве систем, но сложнее в эксплуатации.

Рекомендация: age. Образ закрепить по digest, добавить в Dependabot (CI-01).

## Риски

Потеря приватного ключа = потеря бэкапа: README обязан это объяснять и просить хранить ключ
отдельно. Тест на цикл «зашифровать → расшифровать → restore» потребует Linux и Docker.
