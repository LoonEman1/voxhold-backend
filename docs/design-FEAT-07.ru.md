# Дизайн FEAT-07: интернационализация (EN) и BUG-07

Статус: черновик на утверждение.

## Предложение

- Словари `src/i18n/ru.ts` и `en.ts`, функция `t(key, params)` без библиотек, язык в профиле
  (localStorage, затем настройка аккаунта), ключи типизированы, чтобы TypeScript ловил пропуски.
- Миграция по одному компоненту за PR: механическая замена русских литералов на `t()`; тест,
  что в `en.ts` есть все ключи `ru.ts`.
- Даты и числа через `Intl` с текущим языком.
- BUG-07 делается тут же: backend хранит коды (`author_banned`, `invalid_payload`,
  `send_unavailable`, `retrying`), frontend переводит; старые русские строки в БД показываются
  как есть.

## Риски

Объём (тысячи строк); тексты ошибок backend остаются английскими и русскими вперемешку — нужен
отдельный проход. Бюджет бандла WorkspacePage ≤ 300000 байт: словарь `en` загружать лениво.
