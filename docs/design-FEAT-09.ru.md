# Дизайн FEAT-09: свои эмодзи сервера

Статус: черновик на утверждение.

## Предложение

Таблица `server_emojis(id, server_id, name, mime, content, created_by)` (имя `[a-z0-9_]{2,32}`,
уникально в сервере, до 50 штук). Загрузка PNG/GIF/WebP до 256 KiB с перекодированием и
сжатием по образцу аватаров (`internal/imagelimit`), отдача с `nosniff` и кэшем по `etag`.
Токен в тексте `<:имя:id>`; разбор по образцу `internal/mentions`, рендер во frontend только
через `<img>` с проверенным src.

## Риски

Анимированные GIF и память на декодирование; права на загрузку (после FEAT-05 — отдельный бит);
токены в уведомлениях и поиске нужно превращать в `:имя:`.
