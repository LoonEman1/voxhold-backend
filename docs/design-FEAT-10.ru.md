# Дизайн FEAT-10: автомодерация и жалобы

Статус: черновик на утверждение.

## Предложение

- `automod_rules(server_id, kind, pattern, action)`: запрещённые слова (поиск подстроки без
  регулярных выражений), блок ссылок; действие — отклонить (400) или тихо скрыть.
- Ограничения для новичков: первые N минут участник не может отправлять ссылки и вложения.
- Жалобы: `message_reports(message_id, reporter_id, reason, status)`, «Пожаловаться» в меню
  сообщения, инбокс модераторов с действиями «удалить», «тайм-аут» (QOL-05), «бан».

## Риски

Ложные срабатывания (юникод-нормализация, обходы); приватность жалоб в ЛС (жалоба раскрывает
модераторам текст); нагрузка проверки на пути создания сообщения — O(слов), лимит правил.
