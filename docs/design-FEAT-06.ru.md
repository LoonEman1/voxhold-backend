# Дизайн FEAT-06: Web Push и PWA

Статус: черновик на утверждение. Код — только после одобрения владельца.

## Предложение

- `manifest.webmanifest` и service worker, который не кэширует API (только оболочку).
- Таблица `push_subscriptions(id, user_id, endpoint, p256dh, auth, created_at, last_ok_at)`;
  `PUT/DELETE /api/v1/me/push`.
- Отправка из `internal/notifications` пользователям без активного WebSocket; сообщение без
  текста (канал, автор), чтобы содержимое не уходило через сервис push.
- VAPID-ключи в `.env` (генерирует `install.sh`).

## Главное решение

Шифрование полезной нагрузки по RFC 8291 (ECDH, HKDF, AES-128-GCM) возможно на стандартной
библиотеке, но объёмно и легко ошибиться. Альтернатива — зависимость
(например, `github.com/SherClockHolmes/webpush-go`). Нужно решение владельца о допустимости
зависимости.

## Риски

Подписки протухают (410 Gone) — удалять. iOS требует установленный PWA. Приватность: push-сервис
видит факт и время события.
