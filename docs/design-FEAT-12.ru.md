# Дизайн FEAT-12: TURN поверх TLS

Статус: черновик на утверждение.

## Предложение

Для сетей, где режут UDP: `turns:` на 5349 (или 443 по SNI), сертификат общий с Caddy.
Варианты: (1) coturn читает сертификаты из тома Caddy (`--cert`, `--pkey`), перезапуск при
обновлении; (2) SNI-маршрутизация на 443 через Caddy layer4 (новый модуль — зависимость).
Рекомендация: вариант 1 на порту 5349, `WEBRTC_CLIENT_ICE_SERVERS` дополняется `turns:`;
`install.sh` спрашивает про порт и подсказывает правило файрвола.

## Риски

Права на чтение сертификатов у контейнера coturn (read-only том, пользователь); обновление
сертификата без перезапуска (coturn перечитывает по сигналу); `--no-tcp-relay` (SEC-03)
остаётся: клиент говорит с TURN по TLS, а релей остаётся UDP.
