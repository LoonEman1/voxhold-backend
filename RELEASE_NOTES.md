# Voxhold 2.0.0

Первый общий релиз фронтенда и бэкенда с одинаковым номером версии.

- Ответы на сообщения с переходом к оригиналу и обновлением цитаты после
  редактирования или удаления.
- Пересылка в доступные каналы с сохранением автора. Повтор после ошибки сети
  использует тот же ключ запроса и не создаёт дубликат.
- Реакции: быстрый выбор, раскрываемая палитра, поиск, категории, недавние эмодзи,
  счётчики и список участников при наведении.
- Исправлено первое открытие записей: рабочая область и звонок остаются на месте
  во время загрузки окна.
- Список участников с доступом к каналу обновляется по событиям без ручного
  обновления.
- Единый Gitflow: feature PR → dev → релизный PR в main. В обоих репозиториях
  защищены main и dev; образы, теги и GitHub Releases выпускаются автоматически.
- Go CI проверяет гонки и утечки горутин через профиль runtime Go 1.27.

Правила X.Y.Z: X — глобальные изменения, Y — новые совместимые функции,
Z — исправления текущей минорной версии. Подробности в docs/release-workflow.md.

Для обновления сначала установите backend 2.0.0 и миграцию 24, затем frontend
2.0.0. Перед миграцией сохраните проверенную резервную копию базы данных.
